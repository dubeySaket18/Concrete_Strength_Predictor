# 🏢 AI Concrete Compressive Strength Predictor

An end-to-end Machine Learning web application that predicts the compressive strength of concrete mixes using real-world laboratory data.

## 🚀 Key Features
- **Advanced Machine Learning:** Utilizes a Scikit-Learn Random Forest Regressor trained on 1,030 real-world concrete sample formulations.
- **Interactive Web UI:** Wrapped in a clean, responsive Gradio dashboard featuring adjustable material input sliders.
- **Cloud-Fetched Data:** Features an automated pipeline that pulls dataset matrices dynamically from web URLs, eliminating local storage dependencies.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Gradio
- **Environment:** VS Code / Jupyter Notebooks
